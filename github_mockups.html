⊙ Open Vadibharath opened this parent feature issue · 4 child feature tasks linked

Parent Feature Description

The Student Attendance Management feature defines the core operational requirements for recording, storing, and displaying student attendance within the educational portal.

Main Requirements:

  • Record attendance as Present or Absent for enrolled students
  • Store attendance date, subject/class code, and student details
  • Allow authorized faculty to mark attendance with role verification
  • Display attendance records with real-time percentage computation
  • Prevent duplicate attendance entries for the same student, subject, and session

[FEATURE] Notifications and Alerts

#5
⊙ In Review sai ram and Nithish assigned · Integrated with Attendance Marking & Reports

Feature Specification

The Notifications feature is planned as the fourth main product feature. It establishes proactive communication with students and faculty, alerting them on critical attendance changes.

Planned Notification Tasks:

  • 1. Attendance update notification (instant alert upon faculty submission)
  • 2. Low-attendance alert (automated trigger when attendance falls below 75%)
  • 3. Attendance correction notification (when faculty modifies previously marked record)
  • 4. Notification delivery status tracking (Unread badge, Delivered, Read timestamps)
  • 5. End-to-end notification testing and report integration
Integration Architecture:

The notification module hooks directly into the attendance marking lifecycle and the percentage computation engine. When attendance is saved or recalculated, relevant events are dispatched to the student's notification center.
